# 月次サマリーの伝わりやすさ — 2026-10-09

## 株主の読み方

4つの財務KPIに続き、サマリーを「今月の結論」「要点」「次の打ち手」「リスクと対応」の順に表示する。「なぜ変化したか」「事業の進捗」「AIの売上・効率への寄与」から詳細へ移動できる。

見通し・予定は独立した表示にし、確約・予測・商談の内訳へ案内する。リスクは登録された影響度が高いものを1件表示し、全件へのリンクを付ける。同じ影響度なら登録順。リスク未掲載を「リスクなし」と扱わない。

表示は保存済みコンテンツから構成し、既存の公開Snapshotや承認済みの文章は書き換えない。WebとPDFで同じ説明を使う。

## 毎月の作り方

1. 管理画面で対象月を開き、出来事、売上の理由、利益の理由、課題と対応、AIの変化、次月以降の見通しを入力する。資料名・確認日・実測か推計かも添える。入力状況は入力の有無だけを示し、事実確認済みとは表示しない。
2. 非公開の情報は管理者専用メモへ分ける。非公開メモはAI送信と下書きの対象外。
3. 下書きを作成し、サマリーと変化理由を編集する。未検証の見立てと将来の予定を実績へ書き換えない。
4. 編集ガイドで文章量と未記入項目を確認する。リスクやForward Indicatorsの専用欄は自動転記されないため、人が整える。
5. プレビューで数字・期間・因果の根拠・見通しの確度・AI効果の計測状況を確認し、既存のReview → Approve → Publishを行う。編集・再生成後は再承認が必要。

## 要約の精度を支える変更

- AIへ渡す前年比・増減額は同月の財務Snapshotから計算する。前年が0以下の比較率はnullで渡し、0%と解釈しないよう指示する。
- AI出力は見出し50文字、本文400文字、最大3要点・各100文字、見通し250文字を上限として検証する。形式や文字数を満たさない出力は採用しない。
- プロンプトで数字の根拠、経営者の説明、未検証の見立て、将来情報を区別する。未計測のAI効果や、現預金だけに基づく安全性の断定を避ける。
- AI未接続時は文章整理モード。話題ごとに原文を抜粋し、長い進捗メモによって課題やAIの計測状況が押し出されないようにする。長い抜粋は「…」で示す。このモードではAI用の短文制限を強制せず、編集ガイドで短文化を促す。

編集ガイドは文章量と項目の有無を確認する補助機能。数値や因果の正しさを判定するものではなく、AIによる自動公開も行わない。
