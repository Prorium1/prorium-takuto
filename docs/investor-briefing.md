# Investor Briefing / 編集方針

株主が最初の30秒で経営状態を理解できるよう、レポート冒頭は財務KPI、Executive Summary、出典、目次を維持する。本文は財務報告 → 変化の理由 → 事業報告 → Inside Prorium → AI → 財務状態 → 将来指標 → リスク → CEOコメントの順に読む。

Inside Proriumには開発状況、組織・採用、資金調達、PR・告知、競合・市場、自社サービスの詳細、ユーザー・講師、株主へのお願い、その他の9テーマを用意する。管理者は各記事を「Actual / Committed / Forecast / Pipeline」に分類し、見出しと本文を入力する。空欄のテーマは株主画面に出ない。入力はDraftに保存され、レビュー・承認・公開の既存ワークフローを通過する。既存のPublished Snapshotは書き換えない。

数値・契約・顧客・競合について、AIやテンプレートは事実を作らない。デモの例文はサンプルと明示する。ユーザー・講師の個人情報や、未公表の資金調達条件は掲載前に経営者が確認する。

短い事業動画を入れる場合は、配信元と閲覧権限を先に決める。現時点で動画実体や再生URLは受領していないため、第三者ホストへの自動埋め込みは行わない。次の実装では、投資家認証後にだけ再生できる限定配信または明示的な外部リンクを選び、動画のタイトル・長さ・撮影時期・要点を本文に添える。PDFでは要点の文章を残す。

画面の動きは記事の導入線と操作時の状態変化に限定し、`prefers-reduced-motion` では停止する。財務KPIやForecastの区別をアニメーションだけに依存させない。
