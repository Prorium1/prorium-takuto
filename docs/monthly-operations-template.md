# 月次IRの入力と確認テンプレート

このテンプレートは他のProrium事業にも使える「原文→下書き→人の確認→公開」の運用形式です。数字・契約・日付は確認済みの事実だけを入力し、不明な項目は「未確認」と書きます。

## 毎月の入力

```text
対象月：YYYY-MM

今月あったこと：
・完了したこと、どの事業で起きたことか
・増えた／減った数字（確認済みの値と比較対象）
・変化した理由（根拠があるものだけ）
・課題、遅れ、リスク
・対応したこと、担当、次の確認時点
・AIが売上へ寄与したこと（確認済み実績と予定を区別）
・AIで作業・コストが変わったこと（測定方法も）
・来月の予定（Committed／Forecast／Pipelineを明示）

非公開の検討事項：
・原文保存は管理者専用。生成後の本文・要点・見通しに含まれていないか必ず確認

資料：
・P/L：対象月、単月／累計、確認者
・B/S：月末／期末、確認者
・残高試算表：対象期間、確認者
・その他：目的と対象範囲
```

## スマートフォンでの毎月の作業

1. `/admin/reports` → 対象月 → 文章とPDFで開始。
2. 「今月あったこと」に音声入力や箇条書き → 「入力を保存」。保存通知を確認。
3. 「文章を整理して下書き」、または設定済みならAI生成。
4. 本文・要点・見通し・CEOコメントを確認し「変更を保存」。非公開情報、未確認数値、過度な因果断定を削除。
5. 資料PDFの月・種類・範囲を指定して添付。元資料と一致することを確認。
6. プレビューで株主が30秒で現状、3分で変化・理由・成長要因・リスクを把握できるか確認。
7. レビュー → 承認 → 公開。未保存の本文・原文がある時は先に保存。
8. 訂正は改訂版を作る。公開済みのPDFを置き換えない。

## 問い合わせと事故時

| 状況 | 管理者が行うこと |
|---|---|
| AI生成に失敗 | 保存済みの原文を確認し、文章整理へ切替。または再試行。下書きは自動公開されない |
| 「別の更新」エラー | 未保存の編集を安全に控え、再読み込みで現在の版を確認。古い画面から繰り返し上書きしない |
| PDF添付の結果が不明 | 再読込し添付一覧を確認。既に添付済みなら再アップロードしない |
| PDF取得に失敗 | ログインとアクセス権を確認し再試行。公開URLや共有Storageへ変更しない |
| 数字・資料の訂正 | 改訂版を作り、理由を記載してレビュー・承認・公開。旧版を保持 |
| 退任・権限取消 | 株主権限を取消し、既存セッションの再取得拒否を確認。取得済みPDFは回収できない |
| 機密資料の誤公開 | 信頼された担当へ連絡し、アクセス範囲を止める。監査記録を保持し、DB直接削除やログ改変をしない |

資料の守秘・保持期間・連絡先・法的な条件は会社が確定したものを利用します。ここでは契約条件や期限を設定していません。
